# Enterprise Customer Intelligence & Analytics Platform

## Overview
This project is a Machine Learning application that predicts customer churn using customer demographic and service information.

## Features
- Customer Churn Prediction
- Interactive Streamlit Dashboard
- Data Preprocessing
- Feature Scaling
- Machine Learning Model
- Real-Time Prediction
- Churn Probability Analysis

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Joblib

## Project Structure

Enterprise Customer Intelligence & Analytics Platform/
│
├── app/
├── data/
├── models/
├── src/
├── requirements.txt
├── README.md
└── app.py

## Installation

```bash
git clone <repository_url>
cd Enterprise Customer Intelligence & Analytics Platform
pip install -r requirements.txt
streamlit run app.py
```
